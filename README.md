# AI Student Helpdesk Chatbot

## About the Project
A simple Python-based, rule-based chatbot that helps students with common college-related questions.

## Features
- Greetings and chatbot introduction
- Basic AI and Python information
- Exam and timetable guidance
- Attendance information
- Library and fee guidance

## Technology Used
- Python
- VS Code

## How to Run
1. Install Python.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Run:

   `python Student_Helpdesk.py`

5. Type your question and press Enter.
6. Type `bye` to exit.

## Project Type
College Mini Project — Artificial Intelligence (AICA)
